# PYTHON PROGRAMMING FUNDAMENTALS - 20 HOUR COURSE STRUCTURE

| Class | Chapter Title | Key Sections |
|:-----:|---------------|--------------|
| **1** | **Getting Started with Python** | • What is Programming? • Python Setup (Installation, IDE) • First Program (Hello World!) • Basic Syntax (Comments, Indentation) • Hands-on: Simple print statements |
| **2** | **Variables & Basic Data Types** | • Variables (Naming, Assignment) • Numbers (int, float, Arithmetic) • Strings (str, Concatenation, f-strings) • Booleans (bool, Comparisons) • User Input (input()) • Hands-on: Personal info form |
| **3** | **Data Structures: Lists & Dictionaries** | • Lists (Creating, Indexing, Modifying) • List Methods (append, insert, remove, pop) • Dictionaries (Key-Value Pairs) • Dictionary Methods (keys, values, items) • Tuples & Sets (Brief intro) • Hands-on: Student grade book |
| **4** | **Control Flow: Conditional Statements** | • Boolean Logic Review • Logical Operators (and, or, not) • if Statements • if-else and elif • Nested Conditionals • Hands-on: Number guessing game |
| **5** | **Loops: Repetition in Programs** | • while Loops • for Loops (range, sequences) • Loop Control (break, continue, pass) • Looping Through Lists/Dictionaries • Nested Loops • Hands-on: Multiplication table |
| **6** | **Functions: Writing Reusable Code** | • Defining Functions (def) • Parameters (Positional, Keyword, Default) • Return Values • Variable Scope (Local vs Global) • Hands-on 1: Mini-calculator • Hands-on 2: Temperature converter |
| **7** | **Modules & Import Statements** | • What are Modules? • import, from-import, import as • Standard Library (math, random, datetime) • Creating Your Own Modules • __name__ == "__main__" • Hands-on: Random games, date calculations |
| **8** | **Introduction to OOP** | • Classes and Objects Concepts • Defining a Class, __init__ method • Attributes (Instance vs Class) • Methods • Creating and Using Objects • Hands-on: BankAccount or Student class |
| **9** | **Exception Handling** | • Types of Errors (Syntax, Runtime, Logical) • Common Exceptions (ValueError, TypeError, etc.) • try-except Blocks • Multiple except Clauses • else and finally • Hands-on: Robust input validation |
| **10** | **File Handling** | • File Concepts (Text vs Binary, Paths) • Opening Files, Modes (r, w, a) • Reading Files (read, readline, readlines) • Writing Files (write, writelines) • Context Managers (with) • CSV Files Basics • Hands-on: Note-taking app |
