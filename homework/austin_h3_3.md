# 蝸牛爬樹問題

---

## 題目描述

一隻蝸牛每天沿著一棵樹向上爬。這棵樹的高度為 H 公尺。蝸牛白天能爬上 D 公尺，晚上休息時會掉下 N 公尺。請計算蝸牛需要多少天才能爬到樹頂。

**注意**：當蝸牛在白天爬到或超過樹頂時，就不會再滑落。

---

## 輸入輸出格式

### 輸入說明
- 第一行：整數 T (1 ≤ T ≤ 10)，測試資料組數
- 接下來 T 行：每行包含三個整數 H, D, N
  - H：樹的高度 (1 ≤ H ≤ 1000)
  - D：白天爬升高度 (1 ≤ D ≤ 100)
  - N：晚上滑落高度 (0 ≤ N < D)

### 輸出說明
- 每組測試資料輸出一行，格式：`Days: d`
- 其中 d 為蝸牛到達樹頂所需的天數

---

### 範例
```
輸入：
3
10 3 1
15 5 2
20 4 0

輸出：
Days: 5
Days: 5
Days: 5
```

---

## 解題思路

### 核心概念
逐天追蹤蝸牛的爬行過程，直到到達或超過樹頂。

### 關鍵點：
- 白天先爬升 D 公尺
- 檢查是否到達樹頂
- 如果未到達，晚上滑落 N 公尺
- 重複直到到達樹頂
