# 作業一：身分證字號驗證

#### **作業目標**
請撰寫一個程式來驗證台灣身分證字號的有效性。

---

## 驗證規則

### 1. 字母轉換
將第一個英文字母轉換為2位數代碼

```
A=10 台北市     J=18 新竹縣     S=26 高雄縣
B=11 台中市     K=19 苗栗縣     T=27 屏東縣
C=12 基隆市     L=20 台中縣     U=28 花蓮縣
D=13 台南市     M=21 南投縣     V=29 台東縣
E=14 高雄市     N=22 彰化縣     W=32 金門縣
F=15 台北縣     O=35 新竹市     X=30 澎湖縣
G=16 宜蘭縣     P=23 雲林縣     Y=31 陽明山
H=17 桃園縣     Q=24 嘉義縣     Z=33 連江縣
I=34 嘉義市     R=25 台南縣
```

---

## 驗證規則（續）

### 2. 步驟2計算
- 轉換後的數字：**十位數 + 個位數 × 9**

### 3. 步驟3計算
- 其餘9個數字依序乘上權重 `[8,7,6,5,4,3,2,1,1]` 後相加

### 4. 最終驗證
- 總和 = 步驟2結果 + 步驟3結果
- 如果 `總和 % 10 == 0`：輸出 **real**，否則輸出 **fake**

---

## 範例

```
輸入：T112663836

1. 字母轉換：T → 27
2. 步驟2計算：2 + 7×9 = 2 + 63 = 65
3. 步驟3計算：1×8 + 1×7 + 2×6 + 6×5 + 6×4 + 3×3 + 8×2 + 3×1 + 6×1 = 115
4. 總和驗證：65 + 115 = 180 → 180 ÷ 10 = 18...0 → real
```

---

# 解題指引

---

## 步驟1：理解資料結構

- 確認身分證字號的格式：**1個英文字母 + 9個數字**
- 建立字母與數字的對照表（可使用字典）

## 步驟2：規劃程式流程

- 設計程式的輸入方式（如何讀取身分證字號）
- 規劃三個主要計算階段的順序
- 決定最終結果的輸出格式

---

## 步驟3：實作字母轉換

- 提取輸入字串的第一個字元（英文字母）
- 建立對照表來查詢對應的2位數代碼
- 將2位數代碼拆分為十位數和個位數

## 步驟4：實作步驟2計算

- 使用公式：**十位數 + 個位數 × 9**
- 確保數值計算正確

---

## 步驟5：實作步驟3計算

- 提取身分證字號後面的9個數字
- 建立權重陣列 `[8,7,6,5,4,3,2,1,1]`
- 將每個數字乘上對應權重後加總

## 步驟6：完成驗證邏輯

- 計算總和 = 步驟2結果 + 步驟3結果
- 使用取餘運算子檢查是否被10整除
- 根據結果輸出 "real" 或 "fake"

---

## 步驟7：測試與除錯

- 使用範例 `T112663836` 測試，預期結果為 "real"
- 嘗試其他測試案例驗證程式的正確性
- 檢查邊界情況和錯誤輸入的處理
