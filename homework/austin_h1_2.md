# 作業二：阿姆斯壯數

#### **作業目標**
請撰寫一個程式，找出指定範圍內的所有阿姆斯壯數（Armstrong numbers）。

---

## 阿姆斯壯數定義

一個 **n 位數** 如果滿足以下條件，即為阿姆斯壯數：
- 每個位數的 **n 次方** 總和等於該數本身

---

## 範例說明

```
153 是 3 位數 → 1³ + 5³ + 3³ = 1 + 125 + 27 = 153

370 是 3 位數 → 3³ + 7³ + 0³ = 27 + 343 + 0 = 370

1634 是 4 位數 → 1⁴ + 6⁴ + 3⁴ + 4⁴ = 1 + 1296 + 81 + 256 = 1634
```

---

## 輸入/輸出範例

```
輸入起始值: 100
輸入結束值: 10000
輸出: 153, 370, 371, 407, 1634, 8208, 9474
```

---

## 要求規範

1. 輸入兩個整數 `start` 和 `end`
   - 範圍：1 ≤ `start` ≤ `end` ≤ 1,000,000

2. 輸出範圍內的所有阿姆斯壯數
   - 以逗號分隔

3. 需要正確判斷每個數字是否為阿姆斯壯數

---

## 訓練技能

- 範圍迴圈的處理與優化
- 數學冪次運算的應用
- 數字位數的提取與操作
- 條件判斷與邏輯處理

# 解題指引

---

## 步驟1：理解阿姆斯壯數概念

- 仔細閱讀阿姆斯壯數的定義，確認完全理解
- 手算幾個已知的阿姆斯壯數（如153、370），驗證定義
- 理解「位數」與「次方數」的關係

## 步驟2：分析問題需求

- 確定輸入範圍和輸出格式
- 思考如何有效率地檢查範圍內的每個數字
- 規劃主要的程式流程

---

## 步驟3：設計數字處理函數

- 設計一個函數來判斷單一數字是否為阿姆斯壯數
- 思考如何取得數字的位數（n）
- 規劃如何提取數字的每個位數

## 步驟4：實作位數計算

- 找出計算數字位數的方法
- 考慮使用數學運算或字串轉換來取得位數
- 確保能正確處理各種位數的數字

---

## 步驟5：實作位數提取

- 設計方法來取得數字的每個位數
- 考慮使用除法取餘數或字串轉換的方式
- 確保能正確處理所有位數

## 步驟6：實作冪次和計算

- 對每個位數計算 n 次方
- 將所有位數的 n 次方相加
- 比較總和與原數字是否相等

---

## 步驟7：處理數字範圍

- 使用迴圈遍歷從 start 到 end 的所有數字
- 對每個數字呼叫判斷函數
- 收集所有符合條件的阿姆斯壯數

## 步驟8：格式化輸出

- 將找到的阿姆斯壯數儲存在列表中
- 按照要求以逗號分隔輸出
- 確保輸出格式正確無誤
